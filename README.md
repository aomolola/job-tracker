
# Job Application Tracker API

A REST API built with Python and FastAPI for tracking and managing job applications.

The API allows users to create, view, update, delete, search, filter, and paginate job application records stored in PostgreSQL.

## Features

- Create job applications
- Retrieve all applications
- Retrieve an application by ID
- Update an application
- Delete an application
- Search applications by company or position
- Filter applications by status
- Filter applications by company
- Pagination
- Request validation with Pydantic
- Application status validation using Python Enum
- PostgreSQL database integration
- SQLAlchemy ORM
- Automatic API documentation with Swagger UI
- Environment variable configuration using `.env`

## Tech Stack

- Python 3.12.3
- FastAPI
- Uvicorn
- PostgreSQL
- SQLAlchemy
- psycopg2-binary
- Pydantic
- python-dotenv
- Git
